HOW TO INSTALL Multilevel Language Translator on Mac
=====================================================

Option 1 — easiest if Artifacts download works
1. Download create_translator.py from Artifacts
2. In Terminal:
   cd ~/Downloads
   python3 create_translator.py

Option 2 — if download name differs
   ls ~/Downloads
   python3 ~/Downloads/create_translator.py

Then:
   cd ~/Multilevel_Language_Translator
   ls
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   streamlit run app.py
